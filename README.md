# 有序 · 个人工作台

响应式交互原型，支持电脑、平板和手机布局。源码为原生 HTML、CSS、JavaScript，无构建依赖。

## 本地运行

在项目目录运行 `python3 -m http.server 4173 --directory dist`，然后打开 http://localhost:4173。

## 已实现

- 今日重点、统一任务完成状态、任务编辑、按日期查看计划与时间安排。
- 学习笔记与实际学习分钟记录。
- 基础收入支出与月度统计。
- 运动记录联动每日运动打卡，删除记录后重新计算，保留独立手动打卡。
- 灵感转今日任务，并避免重复转换。
- 手动目标进度、日复盘、头像与名称设置、深色模式和 JSON 导出。

## 原型边界

首次打开含示例数据。所有修改保存在当前浏览器 localStorage，键为 `youxu-prototype-v1`。这不是云端数据库；不同设备及不同网址的数据不互通。请使用测试内容。

尚未实现邮箱验证码、正式用户系统、云端同步、服务端权限隔离、离线应用、提醒推送、预算、重复任务、复杂目标拆解。本站私密访问控制不等于产品内邮箱登录。

## 后续演进

先根据体验反馈调整界面，再引入认证、云端数据库和用户隔离。增加功能时复用任务等实体，联动需明确来源、去重和撤销规则。当前模块代码位于 `dist/app.js`，样式位于 `dist/style.css`。
