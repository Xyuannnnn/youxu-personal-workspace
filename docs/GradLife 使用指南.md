# GradLife 个人工作台｜使用指南

更新：2026-09-16 · finance29

**测试网址：** [进入工作台](https://gradlife-d4g72mcrq3cf4a71f-1486019311.tcloudbaseapp.com/cloud.html)

通过浏览器即可在手机、平板和电脑上使用。首次选择「注册」，输入邮箱并填写 6 位验证码；以后使用同一邮箱登录。收不到验证码时，检查垃圾邮件和页面提示。

## 三步开始

1. 在「偏好设置」修改工作台名称、昵称、头像和主题。
2. 在「今天」添加一件待办，填写名称、日期和预计时间。
3. 保存后确认顶部显示「已保存到云端」。完成任务时勾选即可。

电脑使用左侧导航；手机底部未显示的栏目，可从「探索」进入。

## 功能一览

| 栏目 | 主要用途与入口 |
| --- | --- |
| 今天 | 查看当天待办与时间安排。点击星标设置重点，每天最多 3 项；已完成任务默认折叠。 |
| 日程 | 按周／月安排任务，设置按星期重复的固定安排；可同时加入当天待办。 |
| 学习 | 自定义分类，在分类下建文件夹，整理记录、学习时间和资料链接。 |
| 财务 | 记录与编辑收支，周视图选日期补录；自定义分类，查看月／年统计。 |
| 健康 | 记录运动、分钟、可选热量和感受，查看周／月统计；按需开启经期记录。 |
| 灵感 | 随手记录想法，需要落实时转为今日任务。 |
| 规划 | 写短期／长期规划，关联任务、固定安排与习惯；独立「习惯」页签支持打卡和月／年统计。 |
| 复盘 | 按周／月选择日期，在自由书写区记录想法，可补写、修改和删除。 |
| 偏好设置 | 修改名称、昵称、头像、图标、主题和深色外观。头像不超过 2MB。 |

## 任务与专注

点击任务右侧「···」可编辑或删除，描述可选填。点击时钟图标进入专注页，可开始、暂停、继续或结束；返回后，顶部小入口可再次进入。任务列表显示累计专注时间。

**关闭页面仍会计时，休息请暂停，结束学习请点「结束」。** 结束计时不会自动完成任务；开始另一任务会暂停上一项。专注时间暂不自动计入学习记录分钟。

## 固定安排与个人规划

固定安排依次填写时间、重复星期和日期范围，结束日期默认一年后，可修改。勾选「同时添加到当天任务」，会按对应日期生成独立待办，分别完成和计时。重复待办支持仅修改／删除一次，或这次及以后；修改系列需选生效日。

规划可以自由写正文，日期可选。进入详情，关联已有任务、安排或习惯，也可直接新增。每项行动关联一份规划；关联不会复制记录。固定安排生成的待办继承规划关联，短期规划可归属一个长期规划。删除规划会解除关联，保留原行动记录。

## 补记收支与整理资料

**补录收支：** 在财务周视图点击昨天等日期，再点「记一笔」，默认记入选中的日期；表单仍可调整。分类选「其他」后填写具体名称，保存成功会加入下次可选列表，收入与支出分别保存。已有收支可点「编辑」修正。

**学习分类：** 点击「管理分类」新增、重命名或删除。有内容的分类删除时，需选择其他分类接收；删除文件夹则将记录移回「未分类」。资料链接需为完整网页地址。

**健康记录：** 运动类型选「其他」可填网球等名称，热量单位为千卡。经期功能按需开启，可补录起止日期、点击月历记录每日情况；隐藏后数据保留，不提供预测。

## 保存与换设备

- 顶部显示「已保存到云端」才表示保存成功。必填项缺失时，按表单提示补齐；可选项允许留空。
- 换设备使用同一邮箱；已打开的页面点「刷新云端」读取最新内容。尽量避免多台设备同时编辑。
- 保存失败或版本冲突时，先「导出草稿」备份，再处理或刷新。JSON 备份暂不支持一键导入。
- 云端 PDF 上传和课表自动导入暂未开放，可先使用网页链接。
